## 📖 เกี่ยวกับโปรเจกต์

**Secret Code Generator** เป็นเว็บแอปสำหรับแจกรหัสลับ 4 หลักที่มีทั้งตัวอักษรและตัวเลข ใช้ได้กับงานที่ต้องการให้ผู้เข้าร่วม**ได้รหัสไม่ซ้ำกัน**และ**ไม่เปิดเผยตัวตน** เช่น การจับฉลาก การแจกรหัสเข้าร่วมกิจกรรม หรือการส่งความเห็นแบบไม่ระบุชื่อ

ระบบรับประกันว่ารหัสจะไม่ซ้ำกันแม้ผู้ใช้จะเปิดจากคนละอุปกรณ์ เพราะรหัสทุกตัวสร้างและตรวจสอบที่เซิร์ฟเวอร์กลาง ระบบเก็บไว้เฉพาะรายการรหัส และ**ไม่บันทึกข้อมูลที่ใช้ระบุได้ว่าใครเป็นเจ้าของรหัสไหน**

## ⚙️ หลักการทำงาน

```text
┌──────────────────┐   POST (ไม่มีคุกกี้/ข้อมูลผู้ใช้)   ┌──────────────────────┐        ┌────────────────┐
│   หน้าเว็บ        │ ────────────────────────────────▶ │  Google Apps Script  │ ─────▶ │  Google Sheet  │
│  (GitHub Pages)  │ ◀──────────────────────────────── │  สุ่ม + ตรวจรหัสซ้ำ     │ ◀───── │  รายการรหัส     │
└──────────────────┘          { code: "A7K2" }         └──────────────────────┘        └────────────────┘
```

1. ผู้ใช้กดปุ่ม **สุ่มรหัส** แล้วหน้าเว็บส่งคำขอไปที่ Apps Script โดยไม่แนบคุกกี้หรือ referrer
2. เซิร์ฟเวอร์ล็อกคิวด้วย `LockService` ถ้ามีหลายคนกดพร้อมกัน จะประมวลผลทีละคำขอ
3. ระบบสุ่มรหัสใหม่ เทียบกับรหัสที่มีอยู่ ถ้าซ้ำก็สุ่มใหม่
4. ระบบบันทึกรหัสและเรียงรายการใหม่ตามตัวอักษร เพื่อไม่ให้ลำดับแถวบอกได้ว่าใครสุ่มก่อน
5. รหัสถูกส่งกลับไปแสดงบนหน้าจอผู้ใช้เท่านั้น

**รูปแบบรหัส:** 4 ตัวจาก `A–Z` และ `0–9` ต้องมีทั้งตัวอักษรและตัวเลขอย่างน้อยอย่างละ 1 ตัว (ทั้งหมดประมาณ **1.2 ล้านแบบ**)
