## 📖 เกี่ยวกับโปรเจกต์

**Secret Code Generator** เป็นเว็บแอปสำหรับแจกรหัสลับ 4 หลักที่มีทั้งตัวอักษรและตัวเลข ใช้ได้กับงานที่ต้องการให้ผู้เข้าร่วม**ได้รหัสไม่ซ้ำกัน**และ**ไม่เปิดเผยตัวตน** เช่น การจับฉลาก การแจกรหัสเข้าร่วมกิจกรรม หรือการส่งความเห็นแบบไม่ระบุชื่อ

ระบบรับประกันว่ารหัสจะไม่ซ้ำกันแม้ผู้ใช้จะเปิดจากคนละอุปกรณ์ เพราะรหัสทุกตัวสร้างและตรวจสอบที่เซิร์ฟเวอร์กลาง ระบบเก็บไว้เฉพาะรายการรหัส และ**ไม่บันทึกข้อมูลที่ใช้ระบุได้ว่าใครเป็นเจ้าของรหัสไหน**

```text
┌──────────────────┐   POST (ไม่มีคุกกี้/ข้อมูลผู้ใช้)   ┌──────────────────────┐        ┌────────────────┐
│   หน้าเว็บ        │ ────────────────────────────────▶ │  Google Apps Script  │ ─────▶ │  Google Sheet  │
│  (GitHub Pages)  │ ◀──────────────────────────────── │  สุ่ม + ตรวจรหัสซ้ำ     │ ◀───── │  รายการรหัส     │
└──────────────────┘          { code: "A7K2" }         └──────────────────────┘        └────────────────┘
```

1. ผู้ใช้กดปุ่ม **สุ่มรหัส** แล้วหน้าเว็บส่งคำขอไปที่ Apps Script โดยไม่แนบคุกกี้หรือ referrer
2. เซิร์ฟเวอร์ล็อกคิวด้วย `LockService` ถ้ามีหลายคนกดพร้อมกัน จะประมวลผลทีละคำขอ
3. ระบบสุ่มรหัสใหม่ เทียบกับรหัสที่มีอยู่ ถ้าซ้ำก็สุ่มใหม่
4. ระบบบันทึกรหัสและเรียงรายการใหม่ตามตัวอักษร เพื่อไม่ให้ลำดับแถวบอกได้ว่าใครสุ่มก่อน
5. รหัสถูกส่งกลับไปแสดงบนหน้าจอผู้ใช้เท่านั้น

**รูปแบบรหัส:** 4 ตัวจาก `A–Z` และ `0–9` ต้องมีทั้งตัวอักษรและตัวเลขอย่างน้อยอย่างละ 1 ตัว (ทั้งหมดประมาณ **1.2 ล้านแบบ**)

## ⚠️ ข้อจำกัดที่ควรรู้

เพื่อความโปร่งใส ระบบนี้มีข้อจำกัดดังนี้
- **ผู้ดูแลระบบยังมีอำนาจในการแก้ไขโค้ด:** ผู้ใช้ตรวจโค้ดหน้าเว็บได้โดยตรง แต่พิสูจน์ไม่ได้ 100% ว่าโค้ดที่ deploy บน Apps Script ตรงกับไฟล์ใน repo
- **ประวัติเวอร์ชันของ Google Sheet:** ระบบนี้ปิดฟีเจอร์นี้ไม่ได้ ผู้ดูแลจึงอาจย้อนดูได้ว่ารหัสถูกเพิ่มเข้ามาเวลาใด (สามารถเปลี่ยนไปเก็บข้อมูลใน Script Properties เพื่อลดความเสี่ยงนี้ได้)
- **การเฝ้าดูขณะสุ่ม:** ถ้ามีคนเปิดดูรายการรหัสขณะที่รู้ว่าใครกำลังสุ่มอยู่ ก็อาจจับคู่รหัสกับคนได้
- **DoS:** ผู้ใช้ไม่ต้องยืนยันตัวตน ผู้ไม่หวังดีจึงยิงคำขอจนชนเพดานจำนวนคำขอได้

## 🔍 ตรวจสอบด้วยตัวเอง

ไม่จำเป็นต้องเชื่อเรา ตรวจสอบเองได้ดังนี้
1. **อ่านโค้ด:** ไฟล์ที่รันบนเบราว์เซอร์คือ [`index.html`](index.html), [`style.css`](style.css) และ [`app.js`](app.js) ส่วนโค้ดฝั่งเซิร์ฟเวอร์อยู่ที่ [`backend/Code.gs`](backend/Code.gs)
2. **ดูการรับส่งข้อมูล:** เปิด DevTools (`F12`) → แท็บ **Network** แล้วกดสุ่ม จะเห็นคำขอเดียวที่ไปยัง `script.google.com` โดยส่งไปแค่ `{"action":"generate"}`
3. **ดูข้อมูลที่เก็บในเครื่อง:** DevTools → **Application** → **Local Storage** จะมีแค่ค่าภาษา `scg_lang`

## 🚀 ติดตั้งใช้งานเอง

### 1. Backend: Google Apps Script
1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script**
2. วางโค้ดจาก [`backend/Code.gs`](backend/Code.gs)
3. **Deploy → New deployment → Web app**
   - **Execute as:** Me
   - **Who has access:** Anyone
4. คัดลอก URL ที่ลงท้ายด้วย `/exec`

### 2. Frontend: GitHub Pages
1. Fork หรือ clone repo นี้
2. แก้ `API_URL` ในไฟล์ `app.js`
   ```javascript
   const API_URL = 'https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec';
   ```
3. **Settings → Pages →** Deploy from a branch → `main` / `(root)`
4. ติ๊ก **Enforce HTTPS**

### 3. ก่อนเปิดใช้งานจริง
- ทดสอบสุ่ม 2–3 ครั้ง แล้วรันฟังก์ชัน `resetAllCodes` ใน Apps Script เพื่อล้างข้อมูลทดสอบ
- เปิด **2FA** ทั้งบัญชี GitHub และ Google
- ตั้ง branch protection ให้ `main`

### ⚙️ ตั้งค่าเพิ่มเติมใน `Code.gs`

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `CODE_LEN` | `4` | ความยาวรหัส |
| `MAX_CODES` | `100000` | จำนวนรหัสสูงสุดที่ออกได้ |
| `RATE_LIMIT_PER_MIN` | `60` | จำนวนคำขอรวมสูงสุดต่อนาที |
| `LETTERS` / `DIGITS` | `A–Z` / `0–9` | ชุดตัวอักษรที่ใช้ (ตัด `O`, `0`, `I`, `1` ออกได้ถ้าไม่อยากให้สับสน) |
